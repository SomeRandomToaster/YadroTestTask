# Драйвер I2C-контроллера светодиодов

В этом репозитории реализован драйвер четырёхканального I2C-контроллера светодиодов. Для целей отладки также добавлена возможность запуска тестовых прошивок в эмуляторе QEMU с трансляцией данных, посылаемых по I2C, в сообщения, отправляемые по виртуальному UART-интерфейсу. Тестовые прошивки запускаются на контроллере **STM32F405**.

## Структура проекта
Проект содержит следующие составные части:
* Драйвер контроллера светодиодов (директория **led_control**)
* Заголовочный файл предоставленного API интерфейса I2C (файл **i2c/i2c_api.h**)
* Заглушки функций API интерфейса I2C, отправляющие данные по UART (файл **i2c/i2c_dummy.c**)
* Код для запуска эмуляции микроконтроллера и набор тестов (директория **testing**)

## Сборка и запуск тестов

### Окружение
Для сборки проекта требуются:
* **make**
* тулчейн **arm-none-eabi** (gcc и ld)

Для запуска тестов также потребуется **qemu-system-arm** с поддержкой архитектуры **Cortex-M4** и машины **olimex-stm32-h405**.

### Сборка
Для сборки необходимо выполнить команду ```make <имя цели>```. Список целей сборки приведён ниже:

* **all** (```make``` без аргументов) — генерирует объектный файл драйвера LED-контроллера, в котором не содержатся реализации функций API интерфейса I2C. Файл помещается в директорию *build/obj*.
* **<имя теста> qemu** — собирает прошивку для указанного теста и запускает её эмуляцию.
* **<имя теста> qemu-gdb** — делает то же самое, однако останавливает контроллер для подключения отладчика **gdb** через tcp-порт *1234*.
* **clean** — удаляет директорию сборки (*build*)

### Тесты

* **test-one-ch** — включает 4-й канал на полную яркость
* **test-color** —  устанавливает жёлтый цвет (255, 255, 0)
* **test-multi** — включает на одном контроллере 2-й канал, на другом 4-й. Шина I2C общая.

Всем тестам соответствуют файлы **.c** в директории **testing** с такими же именами


## Пример кода с пояснениями
```
#include "i2c/i2c_api.h"
#include "led_control/led_control.h"

#define LED_ADDR 0x78

int main(void)
{
    uint8_t id;
    // Инициализируем шину
    LED_InitBus(I2C_CH0, I2C_FREQ_400_KHZ); 

    // Получаем ID для дальнейшего взаимодействия с драйвером
    LED_GetDeviceId(&id, I2C_CH0, LED_ADDR); 
    // Переводим контроллер в начальное состояние. Задаём выходной ток и частоту ШИМ
    LED_InitDevice(id, LED_CUR_IMAX, LED_PWM_3_KHZ); 

    // Включаем все каналы
    LED_SetAllChannelsState(id, LED_CH_STATE_ON, 1);
    // Выставляем жёлтый цвет
    LED_SetColor(id, 255, 255, 0);
    // Отключаем красный канал, получаем зеленый цвет
    LED_SetChannelState(id, LED_CH_R, LED_CH_STATE_OFF);
    // Выключаем все каналы
    LED_SetAllChannelsState(id, LED_CH_STATE_OFF, 0);
    // Включаем обратно
    LED_SetAllChannelsState(id, LED_CH_STATE_ON, 0);

    /*
     *Т. к. to_each = 0, снова получаем зелёный цвет. 
     * Если бы to_each был равен 1, нужно было бы заново включать все каналы. 
     */

    while (1)
    {
        ;
    }
}
```

## Имитация I2C

Для имитации данных, посылаемых по I2C используется такие форматы сообщений:
* **CXSYYW** - начало передачи на запись
* **CXE** - конец передачи
* **СXWZZ** - передача байта

X - номер канала, YY - адрес устройства, ZZ - передаваемый байт. Все эти числа 16-ричные.
